# API Money

API Money는 DeepSeek API 잔액을 1분마다 자동 확인하는 개인용 Chrome 확장프로그램입니다.

## 1. 현재 기능

- DeepSeek API Key 저장
- DeepSeek 잔액 조회
- 1분마다 자동 갱신
- 확장프로그램 팝업에 현재 잔액 표시
- 최근 1시간 사용액 표시
- 오늘 사용액 표시
- 마지막 업데이트 시간 표시
- 크롬 확장 아이콘 배지에 잔액 요약 표시
- API Key 삭제

## 2. 설치 방법

1. Chrome 주소창에 아래 주소를 입력합니다.

   chrome://extensions

2. 오른쪽 위의 개발자 모드를 켭니다.

3. 압축해제된 확장 프로그램을 로드 버튼을 클릭합니다.

4. 이 저장소 폴더를 선택합니다.

5. Chrome 오른쪽 위 확장프로그램 아이콘에서 API Money를 고정합니다.

## 3. 사용 방법

1. API Money 아이콘을 클릭합니다.
2. DeepSeek API Key를 입력합니다.
3. 키 저장 버튼을 누릅니다.
4. 잔액이 조회되면 이후 1분마다 자동 갱신됩니다.

## 4. 계산 기준

API Money는 DeepSeek의 잔액 조회 API를 사용합니다.

- 현재 잔액: DeepSeek에서 반환한 현재 balance
- 최근 1시간 사용액: 1시간 전 기록과 현재 잔액의 차이
- 오늘 사용액: 오늘 첫 기록과 현재 잔액의 차이

따라서 이 확장프로그램은 요청별 토큰 사용량을 분석하는 도구가 아니라, 잔액 변화 기준의 간단한 비용 확인 도구입니다.

## 5. 보안 주의

- API Key를 GitHub에 올리지 마세요.
- API Key를 README나 코드에 직접 적지 마세요.
- API Key는 Chrome local storage에 저장됩니다.
- 공용 컴퓨터에서는 사용하지 않는 것을 권장합니다.

- DeepSeek
